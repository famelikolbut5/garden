# Garden

Интерактивная главная страница сказочной оранжереи. Анимированный кот реагирует на положение курсора и нажатия, а движение воды и цветов дополняет атмосферу сада.

[Открыть Garden на телефоне](https://garden.arturkolesnikov.online/)

## Возможности

- Восемь направлений взгляда с переходами между положениями головы.
- Анимация отдыха и приветствие по нажатию на персонажа.
- Анимированный фон, музыка и звуковая реакция кота.
- Экран входа, история сада и полноэкранный режим.
- Курсор с золотым ключом при входе и пером внутри сада.
- Управление с клавиатуры и поддержка настройки уменьшения движения.

## Как устроен проект

Персонаж и фон воспроизводятся отдельными видеослоями. WebGL удаляет зелёный фон персонажа и объединяет слои в одну сцену. JavaScript определяет направление курсора, выбирает переход и сохраняет предыдущий кадр до готовности следующего ролика.

Анимация собрана из подготовленных видео. Взгляд переключается между восемью направлениями; в центре воспроизводится отдельный цикл отдыха. Музыка и голос управляются через Web Audio API.

**Стек:** JavaScript, HTML, CSS, WebGL, Web Audio API, Python.

## Структура

```text
index.html       сцена и элементы главной страницы
style.css        оформление и адаптивная композиция
app.js           видеопереходы, WebGL и звук
showcase.js      вход, навигация и курсор
layers/          видео персонажа, фон и аудио
mobile/          самостоятельная версия с сенсорным управлением
docs/            скриншот и видеозапись
serve.py         локальный сервер с поддержкой HTTP Range
```

## Запуск

Нужны Git и Python 3.10 или новее. Установка зависимостей и сборка не требуются.

```sh
git clone https://github.com/famelikolbut5/garden.git
cd garden
python serve.py
```

Откройте [localhost:8819](http://localhost:8819). Для воспроизведения нужен браузер с поддержкой WebGL и H.264. При размещении на статическом хостинге необходима поддержка HTTP Range для перемотки видео.

## Состав демоверсии

В комплекте интерфейс, видео персонажа и сада, музыка и звуковая реакция. Изображения и анимации подготовлены с помощью генеративных инструментов. В портфолио размещена видеозапись взаимодействия. Сенсорная версия работает на отдельном поддомене.

## На телефоне

Локальный адрес [localhost:8819/mobile/](http://localhost:8819/mobile/).

Удерживайте палец и водите по саду. Кот поворачивается в выбранную сторону, а после отпускания возвращается в центр. Короткое нажатие на персонажа вызывает приветствие. Начатая анимация завершается перед следующим переходом; быстрые движения обновляют цель, а не создают очередь команд.

Перед входом загружаются все медиаматериалы, около 18,5 МБ. На повторных посещениях серверный HTTP-кеш позволяет использовать прежние файлы. Во время игры новые ролики не скачиваются. Используются три видеоэлемента: фон и два сменяемых слота персонажа. Предыдущий кадр остаётся видимым до готовности следующего. Исходные видео не перекодированы.

Музыка включается после нажатия «Войти в Garden», отключается кнопкой звука. При скрытии страницы воспроизведение приостанавливается. Вертикальная композиция показывает кота крупным планом; горизонтальная сохраняет оформление главной страницы. Настройка уменьшения движения включает статичную сцену.

Для хостинга корень сайта направляется на `mobile/`, путь `/layers/` на общую папку `layers/`, а `/icon.svg` на корневую иконку. HTML, CSS, JavaScript и `assets.json` должны перепроверяться при посещении. Для медиа используется длительный кеш с хешем файла в URL. После изменения медиа нужно обновить размер и SHA-256 (первые 16 символов) в `mobile/assets.json`.

Проверено в Chromium с эмуляцией касаний: перетаскивание, возврат в центр, одиночная реакция, серия команд и отсутствие горизонтального переполнения на размерах от 320×568 до 1440×900. Это не заменяет проверку на физических Android и iPhone. Скорость первого входа зависит от сети, плавность от устройства и поддержки H.264/WebGL.
